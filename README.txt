OUR HOUSE — iPad-friendly PWA

Important:
- A PWA must be hosted over HTTPS (or localhost) for service-worker installation.
- Safari on iPad: open the hosted app URL, tap Share -> Add to Home Screen -> Add.
- After the first successful load, the app can work offline.
- Data is stored locally on the device/browser. Backup/Restore can move data between devices.
- Automatic 6-phone synchronization is not included in this offline-only version.
